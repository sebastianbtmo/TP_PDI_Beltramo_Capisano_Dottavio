# TP_PDI_Beltramo_Capisano_Dottavio

## Librerias
- matplotlib 3.11.2
- numpy 2.5.3
- opencv-python 5.0.0.93

## Instalación

- Hacer una copia del repositorio mediante una terminal con `git clone https://github.com/sebastianbtmo/TP_PDI_Beltramo_Capisano_Dottavio.git`.
- Dentro de la carpeta del repositorio, crear un entorno virtual con el comando `python -m venv venv`.
- Activar el mismo con `.\venv\Scripts\activate`.
- Instalar las librerias con `pip install`.

## Uso de los scripts

- Utilizar el comando `.\Scripts\Script_Problema_1.py` para ver la solución del **Problema 1 - Ecualización local de histograma**.
- Utilizar el comando `.\Scripts\Script_Problema_2.py` para ver la solución del **Problema 2 - Validación de planilla de calificaciones**.
